# 简洁风格页面 · 组件样例

## 1. 两套主题 {pill:主题}

一个 HTML 文件里同时装两套主题，靠 `data-theme` 切换，右上角按钮三态循环。

| 主题 | 气质 | 主点色 | 次点色 |
|---|---|---|---|
| 明亮清新 | 暖纸、白纸卡、清透 | 青绿 `#17A398` | 陶土 `#D2705F` |
| 暗黑忧郁 | 石墨蓝、雾面、低饱和 | 雾蓝 `#7FA8C9` | 暗紫 `#A98BB0` |

> 首屏默认哪套由 `--theme` 决定，用户的手动选择存 `localStorage`，刷新不闪白。

## 2. 结构件 {pill:组件}

页面骨架由这几件组成，全部只认 CSS 变量，换主题不动结构：

1. 吸顶药丸导航
   窄屏横向滑动，当前章节高亮
2. 顶部 3px 渐变阅读进度条
   双色渐变，滚动即时更新
3. 目录卡
   4 张，悬浮抬起 7px，960px 以下两列、600px 以下一列
4. 无边框表格
   表头浅底小字、行间发丝线、悬浮微染、外层容器自己横滚
5. 自定义列表符
   无序小圆点、有序浅底数字圆

---

代码块带标题栏和复制按钮，浅色主题下也是浅底，不再是一整块黑：

```sh
python scripts/build_page.py example/demo.md -o demo.html --theme light
python scripts/check_page.py example/demo.md demo.html
```

## 3. 响应式 {pill:适配}

- 960px 以下：目录卡 4 → 2 列
- 600px 以下：目录卡 1 列，Hero 圆角收到 22px，色晕缩小，表格字号 13px
- 表格 `min-width:430px` 放在 `overflow-x:auto` 容器里，页面本身不产生横向滚动
- `prefers-reduced-motion` 关掉所有过渡，`@media print` 去掉导航与阴影

## 4. 验收 {pill:验收}

| 检查项 | 手段 | 通过标准 |
|---|---|---|
| 标签配平 | `check_page.py` | 每类标签开合数相等 |
| 内容零丢失 | `check_page.py` | 源 md 每行都在产物里 |
| 对比度 | `check_page.py` | 小字 ≥ 4.5，大字 ≥ 3.0 |
| 无横向溢出 | 浏览器读 `scrollWidth` | 等于视口宽 |
